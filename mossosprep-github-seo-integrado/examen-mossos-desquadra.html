La convocatòria concreta és sempre la font prioritària. Si hi hagués una modificació de format, prevalen les bases i els anuncis oficials.

Estratègia de preparació

Domina el temari per discriminació

Moltes preguntes no exigeixen només recordar una definició, sinó distingir-la d’una alternativa semblant. Practica especialment competències, composició d’òrgans, funcions i cronologia.

Simula quan ja tens base

Fer simulacres massa aviat pot convertir-se en una cadena de preguntes aleatòries. Primer guanya cobertura del temari; després utilitza simulacres per ajustar ritme, decisió i gestió d’incertesa.

Revisa el motiu de l’error

Classifica les errades: “no ho sabia”, “he confós dos conceptes”, “he llegit malament” o “he canviat una resposta correcta”. Cada causa requereix una solució diferent.

Referència oficial: la web informativa de Mossos sobre el funcionament de l’oposició descriu la subprova de coneixements amb 30 preguntes. Consultar font oficial.

També pots consultar els tests Mossos i la convocatòria 46/26.

Fes el proper simulacre

Practica el format de coneixements, revisa els errors i utilitza’ls per decidir el teu pròxim repàs.
